# EU outreach list, 50 targets

Working list for children's book illustration and design outreach across
continental Europe, in English. Built 2026-09-11.

- `targets.csv` — the list as a spreadsheet (UTF-8 BOM, opens cleanly in Excel).
- `targets.json` — the same data, source of truth for the page.
- `outreach-page.html` — the interactive version published as an Artifact.

Each row carries a LinkedIn search string rather than a profile URL. The search
string finds the person; you confirm the name on their profile before sending.
Profile URLs were deliberately not guessed: sending a note that opens with the
wrong name is the failure this avoids.

Every note is under 200 characters (the free-account cap), contains no em dash,
names the company, and links the matching portfolio section: illustration
targets get `/illustration`, design targets get `/design`, mixed targets get the
site root.

Split: 40 illustration, 7 design, 3 both, across 13 countries.

## Sending pace

Roughly 20-25 invitations a day and up to 100 a week is the safe ceiling, so the
full list is about three days of work. On a free account a personalized note can
only be attached to a handful of invitations per month; Premium removes that
limit but not the weekly cap.
