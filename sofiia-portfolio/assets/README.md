# Hero artwork

`hero.png` is the full-screen illustration behind the landing page.

To swap in a different painting, export it as **`hero.png`** (same name, roughly
2000 × 1264 px or wider) and drop it in this folder — no HTML or CSS changes are
needed. The page crops it to the browser window from the centre, so keep the
hand-lettered name near the middle of the canvas: the small
"Graphic design & illustration" line is positioned just under that point.

The current file is a stand-in painted in code; replace it with the real export.
